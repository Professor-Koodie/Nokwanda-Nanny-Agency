# Nokwanda Nanny Agency

Static GitHub Pages website for Nokwanda Nanny Agency.

## Publish on GitHub Pages

The outer folder is the complete version and includes all slideshow images and the About-page video. In the repository settings, enable **Pages** from the branch containing the outer `index.html` file. Keep the nested folder only if a separate copy is required; it is independently navigable and includes its own policy page.

## Contact and pricing

Pricing is provided on request. Visitors can call **+27 61 492 9047** or use the contact form. The form uses EmailJS, so the EmailJS service, template, and public key must remain configured in `index.html` and `script.js`.

## Agency policies

The agency role, background-check limitations, privacy handling, and non-refundable fee policy are documented in `policy.html`. Nokwanda arranges introductions and interviews; it is not a recruitment company or the employer of providers.
